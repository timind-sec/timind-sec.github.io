通常我们需要将.java文件编译成.class才能正常执行，在命名行中我们通常使用javac来编译，javasist是一个处理字节码的类库，能够动态修改class字节码文件，也可以直接读取到一个java类的字节码，javassist的用法：

​ 1.通过调用ClassPool.get()获取一个CtClass对象。

​ 2.修改它，并且调用CtClass对象的writeFile()或者toBytecode()方法获得修改后的class文件

javassist Demo

ClassPool 是 Javassist 的类池，负责管理类字节码。getDefault() 返回默认的类池，它会扫描系统类路径（包括当前项目的 classpath）来查找类，后续调用get方法，从类池中返回我们需要调用的类，然后再利用反射机制，来获取该类中的say方法。
m.insertBefore("System.out.println(\"Ready to say:\");");在方法体开头插入一行 Java 源代码。这里插入的代码是输出 “Ready to say:”。Javassist 允许插入源代码片段（会被编译为字节码插入到方法中）。

Class c = cc.toClass();将修改的字节码重新编译成class文件，并实例化出一个对象，并调用say方法，整一个的javassist加载类方法的流程就此结束。
